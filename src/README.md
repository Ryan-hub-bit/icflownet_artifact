# `src`

Core ICFlowNet code: graph loading, GT loading, model definitions, training
entrypoints, and lower-level ground-truth generation modules.

## Training Entry Points

- `train_single.py`: trains or evaluates one `SingleTaskGAT` per requested edge
  type. Its paper default disables GCH/GDH for `jumptable` and enables both for
  the other single tasks; explicit hub flags select ablations. It writes
  checkpoints to `<output_dir>/<edge_type>/best_model.pt`.
- `train_multi.py`: trains or evaluates the joint `MultiTaskGAT`. It supports
  package-level split caching through `--split_cache_path`, hub routing flags
  (`--use_gch`, `--use_gdh`), and `--eval_only` checkpoint evaluation.
- `generate_split.py`: creates `split_by_type.json` without launching a full
  training run. The split is package-aware and is reused by `train_multi.py`.

Common edge type names are:

```text
ret
jumptable
indirectcall
tailcall
```

## Models and Shared Code

- `common.py`: edge-type constants, task-name normalization, hub-routing graph
  augmentation, feature extraction, and the shared heterogeneous GAT layer.
- `single_task_model.py`: single-task GAT model for one control-flow relation.
- `multi_task_model.py`: multi-head GAT model that predicts all supported
  control-flow relations jointly.

## Dataset Loaders

- `loadgraph.py`: `JumpGraphDataset`, which loads compressed
  `graph/<idx>.graph.gz` files, applies optional graph filters/reverse edges,
  loads hub candidate metadata, and samples positive/negative edge examples.
- `loadgt.py`: converts per-binary GT JSON files under `res/<binary>/` into
  node-id edge lists for `train`, `eval`, or `allowduplicate` modes.

The expected dataset root is the parent of `graph/`:

```text
<dataset_root>/
├── graph/
│   └── <idx>.graph.gz
├── res/
│   └── <binary>/
├── bintoindex.json
├── indextores.json
└── indextobin.json
```

## Ground Truth Generation

- `groundtruth/static/`: static pipeline used by
  `scripts/getstaticgt_pipeline.sh`. It parses labels, recovers CFG/basic-block
  structure with angr, emits graph artifacts, and builds static GT for
  `ret`, `jumptable`, `indirectcall`, and `tailcall`.

See `src/groundtruth/README.md` and the nested static README for the script-level
breakdown. Dynamic GT is provided with the released data and is consumed by the
evaluation scripts rather than generated by this anonymous artifact.

## Utilities and Metadata

- `util/removeduplicate.py`: function-hash duplicate filtering used by training
  before validation/test evaluation.
- Split metadata is generated by `generate_split.py` or by
  `scripts/generate_train_sample_split.py` under `train_sample/splits/`.

Generated `__pycache__/` folders are interpreter caches and are not required for
reproduction.
